# Content Format for Each Story

Each story should have three layers.

## Layer 1: Raw Intelligence (`raw`)
- What happened
- Who announced it
- Exact source links
- Key numbers and dates
- Confidence level

## Layer 2: Vibe Coding Friendly (`vibe`)
- Explain in plain Japanese
- Why non-engineers should care
- "You can try this today" steps
- Avoid heavy jargon

## Layer 3: Aspiring Engineer (`builder`)
- Technical implications
- Implementation checklist
- Tools/libraries to evaluate
- Risks and known unknowns

## Standard Card Sections
- Summary (2-3 lines)
- Why this matters
- What changed vs before
- Action steps (today / this week)
- Source links

## Quality Checklist
- One claim, one source
- No fabricated metrics
- Separate facts and opinions
- Avoid overpromising practical impact
